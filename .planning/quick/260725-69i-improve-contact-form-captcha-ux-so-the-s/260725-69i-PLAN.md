<objective>
Make the contact form's captcha state legible and mark required fields, so the submit button never sits silently disabled with no explanation.

Two independent, UI-messaging-only improvements — both in `ContactForm.tsx` plus i18n copy:
1. Visible required-field indicators (name, company, country, message) + a legend + an "at least one of email/phone" helper note.
2. Distinguish three captcha states — verifying (brief inline note), errored (distinct actionable banner with WhatsApp/email fallback), ready (button enabled) — instead of one silent disabled button.

Purpose: The Turnstile site key is missing in prod today (separate account-setup task, out of scope), so the widget renders with an empty key and the button never enables with zero user-facing signal. Even once real credentials land, the first ~second of widget load has no feedback either. This plan fixes the messaging around the button without touching gating logic, the schema, the server action, or the Turnstile requirement (LEAD-03 spam defense stays intact).

Output: One modified component, four modified locale message files.
</objective>
