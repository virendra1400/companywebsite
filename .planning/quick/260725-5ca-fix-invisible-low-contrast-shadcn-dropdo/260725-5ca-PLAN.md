<objective>
Bridge shadcn's semantic CSS variables into Tailwind v4's theme namespace so utility classes like `bg-popover`, `bg-card`, `bg-accent`, and `border-border` generate real CSS.

Purpose: The shadcn tokens (`--background`, `--popover`, `--card`, ...) are defined as bare `:root` custom properties but were never registered into Tailwind v4's `--color-*` theme namespace. Tailwind therefore emits NO CSS for `bg-popover`/`bg-card`/etc., so every DropdownMenu/Popover/Dialog/Sheet/Select/Card renders with a transparent background — the LanguageSwitcher menu over the dark hero is nearly unreadable.

Output: A single `@theme inline { ... }` block added to `src/app/globals.css` that maps each existing semantic `:root` token to its `--color-*` key by reference. No color VALUES change; no component (.tsx) changes.
</objective>
