<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous visitor → /insights, /insights/[slug] (SSR) | Public read of published articles only; unpublished/missing slug 404s. |
| CMS article body (richText) → rendered HTML | Payload lexical output is rendered via the trusted @payloadcms/richtext-lexical/react RichText renderer (same as Product descriptions), not raw dangerouslySetInnerHTML. |
| CMS article title → BreadcrumbList JSON-LD | Title flows into structured data through the shared <JsonLd> escaper (05-03), not a second inline render. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-02 | Information Disclosure | /insights + /insights/[slug] queries | medium | mitigate | Every article query filters `published: { equals: true }` (list, detail, generateStaticParams) so a draft never renders publicly, mirroring Products.published (Pitfall 2). |
| T-05-03 | Tampering / Information Disclosure | breadcrumbJsonLd via <JsonLd> | high | mitigate | Article title routes through the single 05-03 <JsonLd> component that escapes '<' — no second inline JSON-LD render on this page. |
| T-05-06 | Tampering (RTL correctness) | byline/meta date in ar | low | mitigate | Dates render via format.dateTime(..., "latn") so ar shows Western numerals (FOUND-03); the e2e ar assertion is the held-out backstop check. |
| T-05-SC | Tampering | npm installs | low | accept | No new package installed. |
</threat_model>
