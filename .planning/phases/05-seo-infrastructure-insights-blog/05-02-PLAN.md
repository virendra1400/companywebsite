## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CMS translation status → emitted hreflang set | The set of locales advertised to crawlers is derived from Payload data; a wrong derivation misrepresents content availability (ranking-signal integrity, not data integrity). |
| env (NEXT_PUBLIC_SITE_URL) → absolute canonical URLs | A wrong/missing base URL produces a canonical that points at the wrong origin (localhost), a self-inflicted SEO-05 conflict. |

| T-05-01 | Tampering (of search-ranking signals) | getTranslatedLocales / buildAlternates | medium | mitigate | Gate every alternate through the fallbackLocale:false existence check (D-07); never emit a hardcoded 4-locale array. Unit tests assert the en-only case emits no phantom alternates. |
| T-05-05a | Information Disclosure | canonical/base URL from env | medium | mitigate | Fall back to localhost only in dev; user_setup declares NEXT_PUBLIC_SITE_URL as a required prod env var. 05-05's phase-gate view-source check confirms no localhost canonical ships. |
| T-05-SC | Tampering | npm installs | low | accept | No new package installed (schema-dts not adopted). |
