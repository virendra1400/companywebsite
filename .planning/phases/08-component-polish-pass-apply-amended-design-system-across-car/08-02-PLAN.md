<objective>
Consolidate three duplicated Button treatments into the `Button` primitive itself (`src/components/ui/button.tsx`) and strip the now-redundant overrides from all 8 call sites: the real brand hover color (repeated 5x), the full-opacity accent focus ring (repeated 6x), and the fragile dark-surface outline override (repeated 2x, now a named `outlineOnDark` variant with an explicit transparent resting background).

Purpose: 08-UI-SPEC Component Audit rows #6/#7/#8. `ui/*.tsx` is owned code under shadcn's own convention — brand-default consolidation belongs there. This is where the site's real button contract stops being copy-pasted and becomes the component's default, so every future button inherits it for free. Contract §4 is explicit that this does not violate the Phase 6 `card.tsx` pass-through precedent: `card.tsx` was preserved as vendor-owned because its overrides are genuinely per-call-site; button's are not.

Output: One modified primitive + five modified call-site files, all class-string/variant-prop diffs.
</objective>
