<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CMS-authored string → inline <script type="application/ld+json"> | Product/article/org strings can contain '<'; injected raw into dangerouslySetInnerHTML they could break out of the script context (server-rendered, but still an output-encoding boundary). |
| anonymous editor of SiteSettings.sameAs | sameAs URLs are admin-authored (Boolean(user)) and rendered as data, not executed — low risk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03 | Tampering / Information Disclosure | JsonLd dangerouslySetInnerHTML | high | mitigate | Single `<JsonLd>` component applies `.replace(/</g, "\\u003c")` to every payload; a unit test proves a '<'-containing CMS string is escaped. No second inline JSON-LD render is permitted (prohibition above). Blocking threshold is high — this is the phase's one genuine injection-adjacent risk, mitigated in-plan. |
| T-05-SC | Tampering | npm installs | low | accept | schema-dts explicitly NOT installed — types are hand-rolled; no supply-chain surface added. |
</threat_model>
