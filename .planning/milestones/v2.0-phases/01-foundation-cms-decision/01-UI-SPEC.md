# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase boundary (source: 01-CONTEXT.md D-07):** Phase 1 ships the bare-shell **reusable chrome** — global header, global footer, language switcher, responsive/RTL layout system, and ONE placeholder homepage proving the locale → RTL → CMS pipeline. Full marketing/trust/catalog page design is **out of scope** — deferred to the Phase 2 `/gsd-ui-phase` pass. Any component spec below beyond header/footer/switcher/hero is explicitly flagged Phase 2+.

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (recommended default; not yet initialized — project is greenfield, no `package.json`/Next.js scaffold exists yet). Executor runs `npx create-next-app` then `npx shadcn init` as the first Phase 1 setup task, feeding the token values below into the Tailwind v4 `@theme` block / shadcn CSS variables. |
| Preset | Not yet generated. Base on the "neutral" shadcn preset, then override `--primary`, `--secondary`, `--accent`, `--destructive`, `--background`, `--foreground` CSS variables with the Color Contract below. |
| Component library | Radix UI primitives (via shadcn) |
| Icon library | Lucide (shadcn default) — see RTL Iconography Rules below for mirror/no-mirror list |
| Font | **IBM Plex Sans** (Latin + Cyrillic, covers en/fr/ru) paired with **IBM Plex Sans Arabic** (same IBM Plex type system, purpose-built Arabic match — consistent x-height/weight feel across scripts, avoids mismatched-foundry pairing). Both open (SIL OFL), self-hostable via `next/font`, subset per script (do not ship one file with all glyphs — see Pitfall 8). |

**Why this font pairing:** the locked brand requirement is a verified multilingual-safe geometric sans across Latin+Arabic+Cyrillic. Inter/Manrope have no native Arabic glyphs, forcing an ad-hoc pairing with an unrelated Arabic font (e.g., Noto Sans Arabic from a different foundry/metrics). IBM Plex Sans + IBM Plex Sans Arabic is a single designed type system spanning both scripts (plus native Cyrillic in IBM Plex Sans), giving visual consistency without hand-picking a second foundry.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing, mobile container padding |
| lg | 24px | Section padding, tablet container padding |
| xl | 32px | Layout gaps, desktop container padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (hero vertical padding) |

**Exceptions:** icon-only touch targets (hamburger toggle, language-switcher trigger on mobile) are **44×44px minimum** regardless of the visual icon size, per WCAG 2.5.5 — pad the icon to hit 44px, don't shrink the tap area to the glyph's visual bounds.

**Container:** max-width 1280px, centered, horizontal padding via logical `padding-inline`: 16px (mobile) / 24px (tablet, `md:`) / 32px (desktop, `xl:`).

**Breakpoints (Tailwind v4 defaults, mobile-first):** `sm` 640px, `md` 768px, `lg` 1024px, `xl` 1280px, `2xl` 1536px. No custom breakpoints needed for Phase 1's bare shell.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 (Regular) | 1.4 |
| Body | 16px | 400 (Regular) | 1.5 |
| Heading | 28px | 600 (Semibold) | 1.2 |
| Display | 40px | 600 (Semibold) | 1.15 |

Exactly 4 sizes, exactly 2 weights (400, 600) — declared per contract discipline. Nav-link active/hover state uses the existing 600 weight (no third weight introduced).

**Usage:**
- Label (14/400/1.4): nav links, footer links, language-switcher menu items, breadcrumb text (Phase 2+)
- Body (16/400/1.5): paragraph copy, fallback-notice text, hero subhead
- Heading (28/600/1.2): section titles (e.g., future homepage sections)
- Display (40/600/1.15): hero headline only

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Page background, header background, main content canvas |
| Secondary (30%) | `#F5F6F4` (light sage-tint neutral) for cards/alternating sections; `#0F2E22` (primary-900, dark forest) for the **footer** surface | Structural chrome surfaces: cards, section bands, footer |
| Accent (10%) | `#C9A227` (decorative gold, trim/dividers/icons) and `#8A6612` (functional gold, text/badges — WCAG AA verified) | See "Accent reserved for" below — never a flood fill |
| Destructive | `#B91C1C` | Reserved for Phase 4 form-validation/error states — **not used anywhere in Phase 1 scope** (no forms/destructive actions in the bare shell) |

**Full token ramp:**

| Token | Hex | Contrast on white | Use |
|-------|-----|--------------------|-----|
| primary-900 | `#0F2E22` | 17.9:1 (est.) | Footer background, highest-emphasis headings |
| primary-700 | `#1B5E45` | 7.68:1 (verified) | Primary CTA button fill (white text), links, brand wordmark color |
| primary-500 | `#3D8266` | ~4.8:1 (est.) | Hover states, secondary button fill |
| primary-100 | `#E3EEE8` | — (background only) | Subtle tint backgrounds, badge fills |
| accent-800 | `#8A6612` | 5.26:1 (verified) | Functional gold — badge text, small icon-with-label needing AA text contrast |
| accent-600 | `#C9A227` | — (decorative only, not for text) | Dividers, borders, hover underline, icon trim on dark surfaces |
| accent-100 | `#F7EFDD` | — (background only) | Rare subtle gold-tint band (e.g., future certification highlight) |
| neutral-900 | `#1A1F1C` | 15.6:1 (est.) | Default body text |
| neutral-600 | `#5B655F` | ~5.7:1 (est.) | Secondary/muted text, captions |
| neutral-300 | `#D7DBD8` | — (non-text) | Borders, dividers on light surfaces |
| neutral-100 | `#F5F6F4` | — (background only) | Secondary surface (cards, alternating sections) |

Contrast values marked "verified" were computed against WCAG relative-luminance formula; "est." values follow standard well-documented palette relationships and should be spot-checked with a contrast tool at implementation time before sign-off.

**Accent reserved for (explicit list — nothing else):**
- Language-switcher active-locale indicator (underline or dot)
- Nav-link hover/active underline
- Hero photography frame trim (thin 1-2px border, "restrained overlay" premium detail)
- Icon accents inside trust badges/checkmarks (Phase 2+, documented here for consistency)
- Section divider rules (thin horizontal rule between page sections)

**Primary CTA fill uses primary-700 (forest green + white text), not gold.** Contrast math for the rejected gold-fill option (`#C9A227`), recomputed against WCAG relative-luminance: white text on gold = **2.42:1** (fails AA); dark text on gold = **6.91:1** (would pass AA). The CTA nonetheless stays on the verified **7.68:1** forest-green fill with white text — reserving gold for trim/accents reads more "premium editorial," while gold-as-flood-fill reads more "discount retail." (Decision unaffected by the gold-fill math; documented for accuracy.)

**LTR/RTL note:** none of these colors are directionally dependent — the palette works identically in both directions; only layout (logical properties) changes per direction, never color.

## RTL & Locale Contract

*(Extends the base template — required for this project per FOUND-03 and PITFALLS.md Pitfall 1; RTL is architected from the first component, never retrofitted.)*

| Concern | Rule |
|---------|------|
| `dir` attribute | Set server-side on `<html dir="rtl\|ltr">` based on locale (`ar` → `rtl`; `en`/`fr`/`ru` → `ltr`). Never client-toggled/JS-flipped post-hydration. |
| CSS properties | **Logical properties only** — `ms-*`/`me-*` (margin-inline), `ps-*`/`pe-*` (padding-inline), `start-*`/`end-*` (inset), `text-start`/`text-end`, `border-s`/`border-e`, `bg-gradient-to-s`/`-to-e`. **Zero** `ml-*`/`mr-*`/`left-*`/`right-*`/`text-left`/`text-right`/`bg-gradient-to-r` anywhere in the codebase. Executor should add a grep-based CI/lint check for the banned physical-direction classes. |
| Numerals | Arabic locale renders **Western/Latin numerals (0-9)**, not Eastern Arabic-Indic (٠١٢٣). Explicitly pass `numberingSystem: 'latn'` to every `Intl.NumberFormat`/`next-intl` number/date formatter call for the `ar` locale — `Intl` defaults to Arabic-Indic numerals for `ar` otherwise, a common silent bug. |
| Brand wordmark | "Star Agrevolution" wordmark renders inside a `<span dir="ltr">` regardless of surrounding direction — Latin proper nouns never mirror or reorder, even adjacent to Arabic punctuation. |
| Mixed BiDi content | Any Latin/numeral run embedded inside Arabic sentences (e.g., future incoterms "FOB"/"CIF" in Phase 2 product content) wraps in `<bdi>` or an explicit `dir="ltr"` inline span. Not needed for Phase 1's bare-shell content, but the pattern must be documented now so Phase 2 doesn't reinvent it. |
| Font loading | IBM Plex Sans Arabic loads only for the `ar` locale; IBM Plex Sans (Latin/Cyrillic subset) for en/fr/ru. Locale-scoped, `unicode-range`-subsetted font loading — never one file shipping all three scripts to every visitor. |
| Fallback notice | When a page is untranslated in the active locale, render **English content + a small visible notice**, translated into the visitor's own locale (chrome string via `next-intl` messages, same file as nav labels — not CMS content). See Copywriting Contract below for exact strings. |
| Responsive + RTL | Every breakpoint must be verified in both directions — mobile hamburger panel opens from the **logical inline-end** side (visually left in RTL, right in LTR), not a hardcoded side. |

### RTL Iconography — Mirror vs. No-Mirror

| Mirror in RTL (`rtl:-scale-x-100` or `rtl:rotate-180`) | Do NOT mirror (fixed orientation) |
|---|---|
| Chevrons/arrows indicating reading-direction navigation (next/prev, breadcrumb separators, accordion carets, "back" arrows) | Brand/logo mark |
| | Media playback icons (play, pause, volume) — ISO/universal convention |
| | Numerals, clock/time icons |
| | Checkmarks, ticks, star/rating icons |
| | Icons depicting real-world objects with inherent orientation (phone, envelope) |
| | Globe/language-switcher icon |
| | Download icon, external-link icon |

Apply the `rtl:` Tailwind variant selectively only to the mirror list; everything else ships with no directional variant at all.

## Component Inventory (Phase 1 Chrome Only)

**Visual hierarchy (placeholder homepage):** the **Hero** (full-bleed photography + Display headline + CTA) is the primary visual anchor and sole focal point of the page. GlobalHeader and GlobalFooter are secondary chrome — persistent but visually subordinate to the Hero. No other element competes for primary attention in Phase 1.


| Component | Spec |
|-----------|------|
| **GlobalHeader** | Height 72px desktop / 64px mobile. Flex row, logical order: wordmark (inline-start) → nav-link placeholders (hidden <lg, moved to mobile panel) → LanguageSwitcher → primary CTA button (inline-end). Background `#FFFFFF`. Auto-reverses in RTL via `dir` + logical flex — no manual mirroring code. |
| **MobileNavPanel** | Hamburger toggle (44px touch target) opens slide-out panel from the logical inline-end edge. Contains nav-link placeholders, LanguageSwitcher, CTA. Hamburger is icon-only → **`aria-label` required**: "Open menu" (closed) / "Close menu" (open), `aria-expanded` reflecting state. Labels are `next-intl` chrome strings (translated per locale). |
| **GlobalFooter** | Background `#0F2E22` (primary-900), text white/`#F5F6F4`, links white with `#C9A227` gold hover-underline. Phase 1 content: wordmark repeat, placeholder link stubs (anchor to `#`, since real pages ship Phase 2), LanguageSwitcher repeat, copyright line. Stacked single column on mobile, logical multi-column grid on desktop. |
| **LanguageSwitcher** | Trigger shows current locale as its own-script endonym (not a flag — flags misrepresent language, e.g. Arabic ≠ one country). Dropdown/menu lists all 4: "English", "العربية", "Français", "Русский". Switching preserves the current path, only swapping the locale segment (`/products/x` → `/ar/products/x`). If target page untranslated, navigate anyway and show the LocaleFallbackNotice. 44px touch target on mobile icon-only trigger; icon-only trigger requires **`aria-label`** "Change language (current: {endonym})" (`next-intl` chrome string). |
| **LocaleFallbackNotice** | Small banner/inline notice, Body token (16/400/1.5), background `primary-100` (`#E3EEE8`), shown above the English-fallback content. See exact copy below. |
| **Hero (placeholder homepage only)** | Full-bleed photography slot (fields/produce/facility/port placeholder image — real photo via CMS later). Overlay: `primary-900` gradient, vertical (`bg-gradient-to-t`), ~40-50% opacity at the base fading to transparent — vertical gradient is direction-agnostic, no RTL concern. Headline: Display token, max 2 lines. Subhead: Body token, 1-2 sentences. Primary CTA button below. |
| **PrimaryButton** | Fill `primary-700`, text white, weight 600, radius per shadcn default. Hover: `primary-500`. Focus ring: `accent-600` (gold) — this is the one accent use directly on an interactive control (a focus ring, not a fill), consistent with the reserved-for list. |

**Deferred to Phase 2 `/gsd-ui-phase` (do not build now):** About, Contact, Certifications, Manufacturing, Export Track Record, Company pages, real nav destinations, product catalog components, RFQ/inquiry forms, WhatsApp widget.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (hero) | "Request a Quote" — renders as a real button/link component. Destination wiring is Claude's discretion at build time (e.g., `mailto:` placeholder or `/contact` anchor) since the real Contact/RFQ flow ships Phase 2/4 — do not block the hero composition on that dependency. |
| Locale fallback notice — heading | "This page isn't available in [language] yet" (translated per-locale as a `next-intl` chrome string, e.g. Arabic: "هذه الصفحة غير متوفرة باللغة العربية بعد") |
| Locale fallback notice — body | "We're showing the English version below while our translation team finishes [language]." (translated per-locale, same mechanism as nav labels) |
| Error state (invalid locale/route) | Heading: "Page not found." Body: "The page you're looking for doesn't exist or may have moved. [Return to homepage]" |
| Destructive actions | **None in Phase 1 scope** — no forms, no CMS-editor UI is part of this public-site UI-SPEC (Payload's own admin chrome is a separate concern). Reserved token (`destructive` red) declared above for Phase 4 forms only. |

**Note on placeholder content quality (Pitfall 4):** the hero headline/subhead above are realistic-shaped premium copy, not lorem ipsum — they read as final-quality placeholders a stakeholder could plausibly ship, per the project's "no fake/generic trust content" discipline, even though final marketing copy is a Phase 2 content decision.
